# GuardDuty vs Inspector vs Security Hub vs Detective

| Service | Primary question |
|---|---|
| [[Amazon GuardDuty]] | Is there suspicious/malicious activity? |
| [[Amazon Inspector]] | Is a supported workload vulnerable? |
| [[AWS Security Hub]] | Which correlated security risks need prioritized response? |
| Security Hub CSPM | Does the environment meet enabled security controls/standards? |
| [[Amazon Detective]] | What context/relationships explain this finding? |

Finding detection, aggregation, investigation, and remediation are distinct operations. Delegate administration and enable coverage separately as required.

Current naming reference: [Security Hub and Security Hub CSPM](https://docs.aws.amazon.com/securityhub/latest/userguide/what-are-securityhub-services.html).
