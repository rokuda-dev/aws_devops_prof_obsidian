# Domain 5 - Incident and Event Response

> [!summary]
> Domain 5 is 14% of the exam and tests event processing, bounded configuration response, and evidence-driven troubleshooting.

## Task 5.1 — Manage event sources to process, notify, and take action in response to events.

Select the source that answers the requirement, then route, process, notify and verify. Native service events, CloudTrail API events, Config compliance and metric alarms are not interchangeable.
