# AWS Certificate Manager

ACM provisions and manages certificates for supported AWS integrations and can import third-party certificates. Managed renewal depends on certificate type and validation. Current ACM also supports eligible exportable public certificates; exported deployments must securely handle the private key and install renewed material outside integrated services.

ACM is not a password/secret store.

- [ACM overview](https://docs.aws.amazon.com/acm/latest/userguide/acm-overview.html)
