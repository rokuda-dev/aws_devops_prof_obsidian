# AWS Firewall Manager

Firewall Manager centrally applies supported WAF, Shield Advanced, security-group, Network Firewall and DNS Firewall policies across organization scope. It requires correct Organizations/administrator and service prerequisites. Accounts, resources, tags, Regions and remediation settings determine actual coverage; it does not automatically protect every resource.

- [Firewall Manager prerequisites](https://docs.aws.amazon.com/waf/latest/developerguide/fms-prereq.html)
