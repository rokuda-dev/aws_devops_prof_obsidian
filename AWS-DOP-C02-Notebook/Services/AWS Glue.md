# AWS Glue

The Glue Data Catalog stores metadata describing data assets, schemas, formats and locations. It supports discovery and governance workflows, but catalog metadata is not by itself a complete business-sensitivity classification or release control. Combine it with explicit ownership, classification and access policy.

- [Glue Data Catalog guidance](https://docs.aws.amazon.com/prescriptive-guidance/latest/serverless-etl-aws-glue/aws-glue-data-catalog.html)
