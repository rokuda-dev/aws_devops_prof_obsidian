# AWS IAM Roles Anywhere

Roles Anywhere lets eligible workloads outside AWS obtain temporary AWS credentials using X.509 certificates. A trust anchor, profile and IAM role define authentication and authorization. It can remove permanent IAM-user keys from on-premises servers, but certificate issuance, private-key protection and revocation remain operational responsibilities.
