# AWS Private CA

AWS Private CA provides managed private certificate-authority infrastructure. Use it for internal PKI, private identities and certificates where relying parties trust the private chain. Private certificates are not automatically browser-publicly trusted. Separate CA administration from certificate issuance and plan revocation, hierarchy and lifecycle controls.

- [Private CA overview](https://docs.aws.amazon.com/privateca/latest/userguide/PcaWelcome.html)
