# Amazon Cognito

User pools authenticate application users and issue tokens. Identity pools can exchange supported identities for temporary AWS credentials mapped to scoped roles, including optional guest access. These are distinct features. Cognito is not the only federation path, and application roles should not receive blanket S3 or DynamoDB permissions.
