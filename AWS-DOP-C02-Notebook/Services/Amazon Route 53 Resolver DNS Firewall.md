# Amazon Route 53 Resolver DNS Firewall

DNS Firewall filters DNS queries that pass through Route 53 Resolver for associated VPCs using rule groups and domain lists. It does not inspect direct-IP traffic or replace a network firewall. Choose fail-open versus fail-closed behavior deliberately.

- [Resolver DNS Firewall](https://docs.aws.amazon.com/vpc/latest/userguide/resolver-dns-firewall.html)
