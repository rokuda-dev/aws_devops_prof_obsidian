# IAM Access Analyzer

Access Analyzer helps identify external, internal and unused access and validates IAM policies. Use findings to review unintended trust or sharing and use policy validation before deployment. A finding is a review signal, not automatic proof that access is malicious.

- [IAM Access Analyzer API overview](https://docs.aws.amazon.com/access-analyzer/latest/APIReference/Welcome.html)
